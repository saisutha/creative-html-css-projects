# Creative HTML & CSS Webpage Projects

A comprehensive collection of 3 modern, responsive, and beautifully designed webpages built using **100% Pure HTML5 and CSS3** (no JavaScript used), selecting one project from each group in the assignment specification.

## Project Highlights & Compliance

### 1. Group 1: Personal Portfolio Website
- **Student Profile**: Hero banner with active status badge, metrics counter (CGPA, projects, hackathons), and code preview card.
- **Skills Matrix**: Categorized into Frontend, Core Programming, and Tools with CSS progress bars and tech tags.
- **Project Showcase**: Card grid displaying real capstone projects with tech stack pills, project descriptions, and source links.
- **Achievements**: Detailed milestone cards highlighting hackathon victories, academic honors, and AWS cloud certification.
- **Contact Section**: Two-column layout with direct contact channels and a complete HTML form.

### 2. Group 2: Online Course Website (EduSphere)
- **Top Announcement Bar**: Promotional code banner with countdown styling.
- **Navbar & Search**: Integrated search bar, navigation links, and sign-up buttons.
- **Course Categories**: Grid of 6 distinct learning disciplines with customized colored badges.
- **Course Cards**: High-resolution image previews, duration badges, bestseller tags, instructor avatars, star ratings, and pricing.
- **Instructor Profiles**: Faculty cards with background experience, courses taught, and student satisfaction ratings.
- **Reviews & Pricing**: Student testimonials quote cards, 3 membership tiers (Individual, Pro, Team), and a quick registration form.

### 3. Group 3: Hospital & Healthcare Website (NovaCare)
- **Emergency Bar**: Prominent red emergency dispatch hotline and 24/7 trauma care alert.
- **Hospital Overview**: 35+ years clinical excellence narrative with zero-infection safety standards.
- **Medical Departments**: Cardiology, Neurology, Pediatrics, Orthopedics, Oncology, and Emergency Care.
- **Doctor Profiles**: Detailed physician credentials (MD, DM, FRCS), OPD visiting hours, and consultation buttons.
- **Health Information**: Patient wellness guides covering heart health, child immunization schedules, and spine ergonomics.
- **Appointment Booking Desk**: Full HTML form capturing patient details, preferred department, doctor, appointment mode, and symptoms.
- **Facility Hours**: Operating schedules for OPD, emergency triage, pathology, and inpatient pharmacy.
